# Семестровая работа № 3: B*-дерево

Реализация структуры данных B*-дерево на Python.

## Требования

- хранение целых чисел;
- операции добавления, удаления и поиска;
- генерация массива из 10 000 целых чисел;
- измерение времени выполнения операций;
- измерение количества шагов или итераций;
- вставка всех элементов с замерами;
- поиск 100 случайных элементов с замерами;
- удаление 1000 случайных элементов с замерами;
- сохранение результатов и расчёт средних значений;
- построение графиков и сравнение практических результатов с теоретической сложностью.

## Структура проекта

- `src/` — исходный код;
- `data/` — входные данные;
- `results/` — результаты замеров и графики;
- `report/` — материалы отчёта;
- `presentation/` — материалы презентации.
